# 前端视觉与交互设计

## 1. 设计目标

AI Mobile Test Studio 是高频使用的桌面设备工具，不采用营销页式视觉。界面以 Apple 平台的克制、清晰和自然动效为参考，在保持信息密度和操作效率的前提下，统一视觉层级、交互反馈和多语言体验。

本设计覆盖 Qt 6 Widgets 主窗口、侧边栏、业务页面、设置页和加载状态。Appium Inspector 与 xterm.js 等第三方嵌入页面保持自身交互协议，只同步宿主容器、字体和外层间距。

## 2. 设计原则

- **内容优先**：主工作区承载设备事实和操作，装饰不抢占首屏空间。
- **克制层级**：使用浅灰背景、半透明白色表面、细边框和少量柔和阴影建立深度。
- **稳定布局**：动画不改变工具栏、表格、终端网格和固定操作区的最终尺寸。
- **即时反馈**：悬停、按下、页面切换和加载均在 300ms 内给出可见响应。
- **可访问性**：文本保持高对比度；尊重“减少动态效果”偏好；语言和字体可即时切换。

## 3. 视觉系统

### 3.1 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `canvas` | `#f5f5f7` | 应用背景 |
| `surface` | `rgba(255, 255, 255, 0.86)` | 顶栏、侧栏和浮层表面 |
| `surface-solid` | `#ffffff` | 表格、输入区和高信息密度卡片 |
| `text-primary` | `#1d1d1f` | 标题和正文 |
| `text-secondary` | `#6e6e73` | 辅助说明和非活动状态 |
| `separator` | `rgba(60, 60, 67, 0.14)` | 分隔线和描边 |
| `accent` | `#0071e3` | 选中、主操作和焦点 |
| `success` | `#34c759` | 已连接、成功 |
| `warning` | `#ff9f0a` | 等待授权、需关注 |
| `danger` | `#ff3b30` | 破坏性操作和错误 |

状态色只用于状态和操作，不作为大面积背景。终端继续使用独立深色主题，避免影响 ANSI 颜色可读性。

### 3.2 字体

- 中文界面加载 `resources/font/cn/LXGWWenKai-Regular.ttf` 和 `LXGWWenKai-Medium.ttf`。
- 英文界面完整加载 `resources/font/us/JetBrainsMono-2.304/fonts/ttf/` 中的 32 个 TTF；首选 `JetBrainsMono-Regular.ttf` 确定字体家族，并按控件字重使用 Regular、Medium 和 Bold 字形。
- 构建后字体复制到 `runtime/fonts/cn/` 与 `runtime/fonts/us/JetBrainsMono-2.304/fonts/ttf/`，运行时只通过应用目录相对路径加载。
- Qt 原生控件通过应用字体和控件字体继承当前语言字体；xterm.js 使用本地 `@font-face` 并由 `TerminalBridge` 动态切换字体家族。
- Appium Inspector 在页面加载完成和语言切换后注入本地 Regular、Medium、Bold 字体规则，覆盖第三方页面的默认字体，同时保持 `letter-spacing: 0`。
- 字号层级为 12/13px 辅助信息、14/15px 正文与控件、20/24px 页面标题；不随窗口宽度连续缩放。

### 3.3 形状与深度

- 主卡片圆角 12px，输入和次级按钮 10px，紧凑工具控件 8px。
- 毛玻璃表面使用半透明白色、低对比度边框和底层浅灰画布模拟材质感。
- 阴影仅用于设置卡片和重要浮层，采用低透明度、大模糊半径，不在表格行和嵌套控件上叠加。
- 不在卡片中继续放装饰卡片；分组内部使用留白和分隔线。

## 4. 页面结构

### 4.1 应用框架

- 顶栏高度 68px，展示产品名称、通知、设备中心和设置入口。
- 侧边栏宽屏为 252px，窄屏为 220px；内容超高时独立滚动，设备状态固定在底部。
- 主工作区使用单层 `QStackedWidget`，页面自己管理业务滚动区域。
- 最小窗口尺寸为 1080×700；宽度小于 1280px 时收紧侧栏和外边距，不隐藏关键操作。

### 4.2 设置页

设置页提供两个即时生效的偏好：

- 语言：中文 / English 分段选择器。
- 动态效果：开关；关闭后禁用页面位移和按钮缩放，仅保留必要的状态变化。

语言选择写入 `QSettings`。切换后主窗口、导航、设置页和已注册的常用业务文案立即刷新，同时应用对应字体；重启后保持选择。

## 5. 动效规范

| 场景 | 时长 | 曲线 | 行为 |
| --- | --- | --- | --- |
| 页面进入 | 240ms | `OutCubic` | 透明度 0→1，水平位移 14px→0 |
| 按钮悬停 | 140ms | `OutCubic` | 视觉缩放 1→1.008，保持命中区域不变 |
| 按钮按下 | 90ms | `OutCubic` | 视觉缩放到 0.985，透明度降至 0.96，松开后恢复 |
| 加载进度 | 连续 | 原生定时器 | 蓝色进度块或不确定进度，不阻塞 UI 线程 |

动画只变更合成属性，不触发布局重排；每个按钮只在交互期间启用图形效果，结束后立即释放离屏缓存。侧边栏工作区按钮不做缩放，只保留按下透明度反馈，避免导航图标和文字在窄栏中产生抖动。页面切换动画只作用于新页面，终端、视频镜像和高频图表不参与整体缩放。

## 6. 国际化策略

- 新增用户文案必须通过 `ui::text()` 创建，禁止直接把可见中文写入 `QStringLiteral`。
- `AppPreferences` 保存当前语言、字体家族和动态效果偏好。
- 已有页面逐步纳入内置中英词典；未收录的设备原始输出、包名、文件名和命令保持原样。
- 动态状态文案在状态刷新时重新调用 `ui::text()`，不能缓存已翻译文本作为业务事实。
- 翻译不改变协议字段、ADB 参数、路径、日志正文和用户数据。

## 7. 性能与验收

- UI 主线程不等待字体加载以外的外部 I/O；字体文件来自本地 runtime。
- 进程表以 PID 为稳定键做差量增删改，禁止每次采样全量 reset；自动采样周期为 8 秒。
- 进程应用图标由后台小批次提取，UI 每 8ms 最多解码一个 PNG，只通知实际命中包名的行；滚动期间暂存采样，滚动空闲 180ms 后合并。
- xterm.js 输出每次只允许一个未确认写入，单块不超过 32KB、块间隔 8ms，C++ 待处理缓冲上限为 4MB；页面隐藏或标签进入后台后暂停投递。
- ConPTY 宿主在 8ms 窗口内合并输出，每批不超过 64KB，降低 Qt 进程间信号与 WebChannel 调用频率。
- 常规窗口和 150%/200% DPI 下，导航文字、按钮、表头和状态标签不得重叠。
- 页面切换和按钮动画目标为 60fps；镜像、终端大输出和性能采样期间不能出现明显卡顿。
- 关闭动态效果后页面立即切换，按钮不缩放。
- 中文模式使用霞鹜文楷，英文模式使用 JetBrains Mono；字体缺失时回退系统无衬线字体并保持功能可用。
- 应用重启后保留语言与动态效果选择。
