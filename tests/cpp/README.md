# C++ Tests

桌面端模型、服务适配器和关键 UI 状态测试放在此处。

- `studio_control_server_smoke`：Studio Control 分帧、认证和稳定工作区路由。
- `studio_operation_manager_smoke`：独立 ADB 操作并发、结果解析和设备动作资源锁。
- `automation_artifact_service_smoke`：自动化目录创建、HTML 扫描和脚本/报告分类。
- `conpty_session_smoke`：ConPTY 输入输出、resize、退出和真实 OpenCode 版本启动。
- `appium_service_smoke`：外部 Appium 复用、缺失运行时和随包服务启动。
